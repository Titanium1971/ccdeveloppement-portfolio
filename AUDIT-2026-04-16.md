## 4. Problemes Identifies

### Critiques (impact SEO direct)

| # | Probleme | Pages | Impact |
|---|----------|-------|--------|
| 1 | **OG tags (og:title, og:description, og:url, og:image) manquants** | `devis`, `estimateur`, `guide-tarifs`, `comparatif-tarifs`, `seo-local-herault`, `creation-site-web-agde`, `mentions-legales`, `rgpd-confidentialite` | Mauvais affichage lors du partage sur reseaux sociaux |
| 2 | **Twitter Card manquante** | Memes pages que ci-dessus + `guide-seo-local`, `estimateur` | Pas de preview Twitter/X |
| 3 | **Schema.org manquant sur pages de services** | `seo-local-herault`, `creation-site-web-agde` | Pas de rich snippets pour les services cles |
| 4 | **Meta description manquante** | `comparatif-tarifs.html` | Google genere un snippet automatique (moins optimise) |
| 5 | **Canonical manquant** | `comparatif-tarifs.html`, `merci.html` | Risque de contenu duplique |

### Importants (qualite et performance)

| # | Probleme | Detail |
|---|----------|--------|
| 6 | **Accents manquants dans les H1** | `seo-local-herault.html` ("Herault" sans accent), `creation-site-web-agde.html` ("Creation" sans accent) — probleme de coherence linguistique |
| 7 | **CSS inline duplique** | Chaque page HTML contient son propre bloc `<style>` avec du CSS redondant — pas de fichier CSS externe partage |
| 8 | **Fonts en format OTF** | 3 fichiers Morena en `.otf` au lieu de `.woff2` — impact sur le temps de chargement (WOFF2 est 30% plus leger) |
| 9 | **og:image non defini** | L'image `og-image.jpg` est referencee dans le schema.org LocalBusiness mais jamais dans les balises `<meta property="og:image">` |
| 10 | **Pas de `<link rel="preconnect">`** | Domaines externes charges sans preconnect : `app.cal.com`, `formspree.io`, `clarity.ms`, `googletagmanager.com` |

### Nice-to-have

| # | Amelioration | Detail |
|---|-------------|--------|
| 11 | Breadcrumbs visuels | Presents en schema.org sur le blog mais pas affiches visuellement sur les pages de services |
| 12 | Skip-to-content | Pas de lien d'accessibilite "aller au contenu" |
| 13 | Minification JS | Les scripts inline (analytics, estimateur) ne sont pas minifies |
| 14 | SRI sur scripts externes | Lenis et Cal.com charges sans Subresource Integrity |

## 7. Performance & Technique

### Points positifs

- Pas de framework lourd — HTML statique rapide
- Fonts preloadees (`<link rel="preload">`)
- Images minimales (SVG pour le logo, gradients CSS)
- `content-visibility: auto` sur certaines sections
- `font-display: swap` sur toutes les polices
- Heberge sur Cloudflare Pages (CDN mondial, SSL auto, HTTP/2)

### Points a ameliorer

| Element | Actuel | Recommande |

| Format polices | OTF | WOFF2 |
| CSS | Inline duplique | Fichier externe partage |
| JS | Non minifie | Minification |
| Preconnect | Absent | Ajouter pour domaines externes |
| Images | Pas de lazy loading | `loading="lazy"` (peu d'images, impact faible) |
